# Stratagem Hero Expanded

Stratagem Hero Expanded now ships inside the **[Vanilla Plus Megapack](https://github.com/CowboyBingus/VanillaPlusMegapack)**, the
HellForge code mod that holds all twenty-five CowboyBingus Helldivers 2 mods in one download. Each mod is a component
you switch on or off in the pack's settings. Stratagem Hero Expanded's C source is in
[`src/components/stratagem_hero_expanded`](https://github.com/CowboyBingus/VanillaPlusMegapack/tree/main/src/components/stratagem_hero_expanded).

The standalone Lua mod (v1.0 and earlier, for the Lua mod loaders) is on the
[`legacy`](https://github.com/CowboyBingus/StratagemHeroExpanded/tree/legacy) branch. Its releases and tags are unchanged.
